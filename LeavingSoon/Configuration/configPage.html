Leaving Soon

Help

Reads the collections Maintainerr fills and shows viewers, inside Jellyfin, which movies and series are about to be deleted and when. Nothing is written to Maintainerr.

Maintainerr

As reached from the Jellyfin server, e.g. http://maintainerr:6246 when both run in the same Docker network.
Sent as X-Api-Key. Leave empty when Maintainerr has no authentication.

Display

The web client needs the plugin's script in its index.html once: contrib/jellyfin-leaving-soon-init.sh does it for linuxserver images (custom-cont-init.d).
